AI Amplify Project Submission
Project Overview
This repository contains the completed deliverables for the AI Amplify Microsoft 365 Copilot project. The project demonstrates the use of generative AI and Microsoft 365 Copilot to analyze supply chain issues, coordinate a cross-functional meeting, analyze supply chain data, and communicate findings through a stakeholder presentation.
The submission is organized by task. Each task includes the relevant Copilot prompts and generated outputs.
Task 1 – Problem Identification and Action Prioritization
Purpose: Analyze supply chain email communications to identify critical issues and determine actionable next steps.
Included files:
Task 1 Copilot Prompts.docx – Contains the Copilot prompts used for Task 1 and a brief description of each prompt’s purpose.
Supply Chain Issues Review.docx – Contains the completed supply chain issues review, including:
Introduction
Outline of Business Problem
Action Items
Conclusion
Three critical supply chain issues
Five actionable next steps
Task 2 – Cross-Functional Meeting Coordination and Action Planning
Purpose: Create and document a cross-functional meeting addressing the identified supply chain issues and develop an action plan based on the provided meeting transcript.
Included files:
Task 2 Copilot Prompts.docx – Contains the Copilot prompts used to create the meeting materials and analyze the meeting transcript.
Meeting Invite Screenshot(s) – Shows the Supply Chain Issues Review meeting invitation, fictitious stakeholders, meeting purpose, and bullet-point agenda.
Supply Chain Issues Review and Action Plan.docx – Contains the meeting summary and action plan, including:
General Strategies
Immediate Actions
Short-Term Actions (1–3 Weeks)
Ongoing Actions
Task 3 – Supply Chain Risk Analysis and Mitigation Strategies
Purpose: Analyze supply chain performance data to identify delivery risks, supplier performance issues, compliance implications, root causes, and mitigation strategies.
Included files:
Task 3 Copilot Prompts.docx – Contains the Copilot prompts used for the Excel analysis and Word report.
Expanded Supply Chain Metrics.xlsx – Contains the supply chain data and analysis, including:
Average delivery timeline by risk level
On-time delivery analysis for CRB-123, BIND-567, and COAT-890
Supplier performance breakdown
Supply Chain Issues Analysis Report.docx – Contains:
Executive Summary
Component Overview
Compliance Implications
Root Cause Analysis
Mitigation Strategies
Task 4 – Stakeholder Report Creation and Presentation
Purpose: Communicate the supply chain analysis and proposed remediation strategy to stakeholders through a professional presentation.
Included files:
Task 4 Copilot Prompts.docx – Contains the Copilot prompts used to generate and refine the presentation.
Supply Chain Issue Compliance Report.pptx – Stakeholder presentation containing:
Title Slide
Summary of Key Issues
Data Insights from Excel Analysis
Proposed Solutions
Implementation Plan
Copilot-generated speaker notes
How to Navigate the Submission
Begin with the Task 1 folder to review the initial identification and prioritization of the supply chain issues.
Continue to the Task 2 folder to review the meeting invitation, meeting documentation, and resulting action plan.
Review the Task 3 folder for the Excel-based supply chain data analysis and detailed risk assessment report.
Finish with the Task 4 folder to review the stakeholder presentation and speaker notes.
Each task’s Copilot Prompts document provides the prompts used to generate or refine that task’s deliverables.
Submission Structure
The repository is organized into separate folders for Tasks 1 through 4 so that each task’s prompts and outputs can be reviewed together.
All project files, prompts, supporting materials, and this README are included as part of the final AI Amplify project submission.AI Amplify Project Submission
